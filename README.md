# AntiScanner

**AntiScanner — это скрипт, который автоматически настраивает брандмауэр для блокировки подсетей, связанных со сканерами ГРЧЦ (СКИПА), Nessly Group (VK), Censys, Shodan и другими.**

# Использование

**`bash <(curl -Ls https://raw.githubusercontent.com/sngvy/AntiScanner/refs/heads/main/AntiScanner.sh)`**
